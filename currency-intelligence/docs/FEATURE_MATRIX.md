## 横断要件

| 要件 | 状態 | 備考 |
| --- | --- | --- |
| Decimal / 最小通貨単位計算、Double 禁止 | ✅ | `packages/core/src/dec.ts`, `money.ts`。JS の `number` は API ペイロードの受け取り直後に文字列化(`numberToDecString`)して以降は BigInt |
| 全レートに出典・時刻・種別・確定/推定 | ✅ | `RateQuote` 型と `validateQuote()`。UI の「このレートについて」で表示 |
| クロスレートの同時刻性チェック | ✅ | `cross()`: 許容時差外は `confidence: "estimated"` + notes |
| 丸めの明示 | ✅ | 7 モード(java.math.RoundingMode 相当)。結果に `roundingMode` を記録 |
| 通貨廃止・ゼロ/負値・桁オーバー・逆レート・破損キャッシュ | 🟡 | 負値/ゼロ/オーバーフロー/逆レート/未知通貨は例外。キャッシュ破損は `load()` で初期値にフォールバック。通貨廃止は未 |
| stale-while-revalidate、provenance 付き永続化 | ✅ | `RateCache`(テスト済み)。Web では localStorage |
| 不明要素を 0 とみなさない比較 | ✅ | `comparePayments()` の `ranking: "undetermined"` |
| 割り勘の不変条件 sum(shares)=total | ✅ | `split.ts` + プロパティテスト |
| A→B→A 誤差境界 | ✅ | `rates.test.ts` のプロパティテスト(1 円以内) |
| 多言語(ja/en/th) | ⬜ | 通貨名は ja/en のみ。UI は ja のみ |
| アクセシビリティ(44pt、VoiceOver、Reduce Motion) | 🟡 | ボタン min-height 44px、aria-label、`prefers-reduced-motion`。VoiceOver 実機未確認 |
| ダーク/ライト | ✅ | システム連動 |
